# Riverside Community Hub

A full-stack membership, facility booking, programme management and donation
platform for Riverside Community Hub.

## Project Overview

Riverside Community Hub is a nonprofit community centre that provides:

- Community programmes
- Youth activities
- Gym facilities
- Meeting and event spaces
- Equipment
- Food-parcel donation drives

The platform replaces paper-based and WhatsApp-based processes with one
centralized web application.

## Technology Stack

### Frontend

- React
- TypeScript
- Vite
- React Router
- Tailwind CSS
- Lucide React

### Backend

- Node.js
- Express
- TypeScript
- Zod

### Database & Authentication

- Supabase
- PostgreSQL
- Supabase Auth
- Row Level Security
- Supabase Storage

### Deployment

- Frontend: Vercel
- Backend: Render
- Database/Auth/Storage: Supabase
